# Directory Index

This file describes what the current public repository paths are for.

## Active public files

`ledger.csv`

Active public hash ledger. Each row should describe one active private artifact and record SHA256 plus audit metadata.

`strategy_registry.csv`

Registry of active and deprecated strategy ids.

`scope.md`

Active audit boundary and legacy exclusion rule.

`AUDIT_PUBLIC_POLICY.md`

Public-side policy for ledger coverage, meaningful comments, correction rows, and publisher-computed proof fields.

`PUBLICATION_PROTOCOL.md`

Strategy-neutral producer/publisher workflow.

`DIRECTORY_INDEX.md`

This human-readable directory map.

`FILE_CATALOG.csv`

Machine-readable catalog of current paths and semantic descriptions.

`LEDGER_COMMENT_GUIDE.md`

Examples and rules for meaningful ledger comments.

`migration_report.json`

Machine-readable migration record retained for traceability.

## Legacy directories

`legacy/old/`

Deprecated pre-migration public material. Kept for transparency and excluded from active ledger scope.

`legacy/old/legacy_ledger.csv`

Old public ledger from the deprecated non-causal single-strategy layout. Historical only.

## File role

This file is the human-readable map of the public repository. It explains which files are active ledger documents, which files are policy documents, and which directories contain deprecated legacy material.
